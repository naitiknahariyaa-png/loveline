# 💖 LoveLink v3 — Bollywood & Jellyfin Cinema Edition

The ultimate romantic couple watch party, voice-chatting, games, and permanent memory vault app.

---

## 🌟 What's New in v3:

### 1. 🍇 Official Jellyfin Media Server Integration (`github.com/jellyfin/jellyfin`)
- Connect any private home or remote **Jellyfin server instance** via URL & API Key (`/api/jellyfin/connect`).
- Streams your self-hosted high-definition Bollywood, Hindi shows, and family media collections directly in the cinema watch party.

### 2. 🌹 Bollywood Hindi Romantic Cinema Catalog
Preloaded with popular Hindi movies:
- **Dilwale Dulhania Le Jayenge (DDLJ)** (1995)
- **Yeh Jawaani Hai Deewani (YJHD)** (2013)
- **Jab We Met** (2007)
- **Aashiqui 2** (2013)
- **Rocky Aur Rani Kii Prem Kahaani** (2023)
- **Veer-Zaara** (2004)

### 3. 🛋️ Popular Romantic Hindi Web Series
Binge-watch couples' favorite Hindi series:
- **Little Things** (Dhruv & Kavya's sweet relationship goals)
- **Mismatched** (Campus coding & love chemistry)
- **Flames** (90s-nostalgia tuition romance)
- **Permanent Roommates** (Long-distance couple moving in together)

### 4. ⏸️ Real-Time "Partner Stopped Movie" Alert System
- When partner A presses **Pause** or **Stops**:
  - Chat instantly records: `⏸️ [Partner] stopped the movie at 14:32`.
  - On-screen romantic alert toast pops up on partner B's screen: `⏸️ [Partner] paused the movie! Waiting for you...`
  - When resumed: `▶️ [Partner] resumed the movie! Enjoy together 💕`

### 5. 📲 Multi-Device Auto-Resume & Permanent Chat Vault
- Close your phone or PC browser anytime; reopening **automatically restores you directly into your last room and chat history**.
- Full text messages, voice recordings, and files are permanently saved on disk (`data/messages.json`).

### 6. 🎙️ Voice Notes, Exploding Heart Touches, Compatibility Quiz & Memory Vault
- Whisper voice notes recorded via microphone with dynamic wave visualization.
- Virtual touches (💋 Kisses, 🤗 Warm Hugs, 🥺 Miss You, 💖 Exploding Hearts).
- Couple Compatibility Quiz (10 love & funny questions with real-time match detection).
- Memory Vault with milestone dates, pictures, and notes sealed forever.
